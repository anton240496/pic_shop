# 🖼️ Pic Shop — интернет-магазин картин

Интернет-магазин картин эпохи Возрождения. Проект выполнен на **Vue 2 (Options API)** с использованием **Webpack**.

---

## 🚀 Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone <ссылка_на_репозиторий>
cd pic_shop

# 2. Установите зависимости
npm install

# 3. Запустите проект в режиме разработки
npm run serve
```
Проект будет доступен по адресу: [http://localhost:8080](http://localhost:8080)





## 📋 Требования

- **Node.js** версии 16 или выше
- **npm** версии 8 или выше

---

## 🛠️ Технологии

- **Vue 2** (Options API)
- **Webpack** (сборка)
- **CSS** (стилизация)
- **localStorage** (сохранение состояния корзины)

---

## 📌 Функционал

- 🔍 **Поиск** по названию картин (мгновенная фильтрация)
- 🛒 **Кнопка "Купить"** с тремя состояниями:  
  `Купить` → `⏳ Обрабатывается...` (2 сек) → `✅ В корзине`
- 💾 **Сохранение состояния** корзины в `localStorage` (после перезагрузки страницы)
- 🖼️ **Модальное окно** с описанием, ценой и слайдером изображений (3 фото)
- ⌨️ **Горячие клавиши**:
  - `Ctrl+F` / `Cmd+F` — фокус на поиск
  - `/` — фокус на поиск
  - `Escape` — очистка поиска / закрытие модального окна
  - `←` / `→` — переключение слайдов
- 📱 **Адаптивность** до 360px
